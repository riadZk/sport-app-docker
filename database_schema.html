🔗 Table Relationships

From Table Relationship To Table Description
users → belongsTo roles User has one role
teams → belongsTo users Team has one owner
teams → belongsTo sport_categories Team belongs to sport category
team_members → belongsTo teams, users Junction table for team membership
fields → belongsTo users, sport_categories Field has owner and sport type
field_availabilities → belongsTo fields Availability slots for a field
offers → belongsTo fields Promotional offers for field
bookings → belongsTo fields, users Field reservation by user
games → belongsTo fields, teams (x2) Game between two teams at a field
game_players → belongsTo games, users, teams Players participating in a game
results → belongsTo games One result per game
challenges → belongsTo teams (x2), fields Challenge between two teams
challenge_histories → belongsTo challenges, users Status history of challenge
player_stats → belongsTo users Aggregated player statistics
